# Club Deportivo Olimpo - Sitio Web Oficial

## Propósito de mi proyecto
Este sitio web ha sido diseñado para promocionar las actividades y disciplinas del **Club Deportivo Olimpo**. 

Su objetivo principal es facilitar la comunicación con nuevos socios y unificar la información institucional, permitiendo a los usuarios conocer las instalaciones mediante contenido multimedia e inscribirse a través de un formulario directo.

## Tecnologías Utilizadas
- **HTML5**: Estructura semántica.
- **CSS3**: Diseño responsivo y efectos visuales.
- **Google Fonts**: Tipografías personalizadas (Montserrat y Roboto).
- **Formspree**: Gestión del backend para el formulario de contacto.
